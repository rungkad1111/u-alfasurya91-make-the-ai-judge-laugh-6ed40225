# Make the AI Judge Laugh

[![Make the AI Judge Laugh](https://make.fun/badge/u-alfasurya91-make-the-ai-judge-laugh-6ed40225.svg)](https://make.fun/c/u-alfasurya91-make-the-ai-judge-laugh-6ed40225)

One original one-line joke about office life (under 200 characters), written
for the [Make the AI Judge Laugh](https://make.fun/c/u-alfasurya91-make-the-ai-judge-laugh-6ed40225)
competition on make.fun, where a judge model picks the funniest entry head to head.

## Entry

> The office printer only jams when the document is urgent, which is how I found out it reports directly to my manager.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Requires Node 22.18+ (the grader runs Node 22.23.4). No dependencies.
